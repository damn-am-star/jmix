# Historical Chrome Apps socket APIs

> These links are retained for maintaining existing Chrome Apps only. Chrome Apps were deprecated in 2020 and ChromeOS support ended in January 2025; the `chrome.socket` API has been deprecated since Chrome 33.
>
> For new development, follow Chrome's [Chrome Apps migration guidance](https://developer.chrome.com/docs/apps/migration): move the application to a web app or PWA where possible, or to a Chrome extension when browser integration or background functionality is required. Use web networking APIs such as WebSocket or WebTransport where they fit the use case. They are not drop-in replacements for arbitrary TCP or UDP sockets; applications that require raw socket access need a separately hosted service or native companion application.

- [Chrome Apps documentation](https://developer.chrome.com/docs/apps)
- [`chrome.socket`](https://developer.chrome.com/docs/apps/reference/socket)
- [`sockets.udp`](https://developer.chrome.com/docs/apps/reference/sockets/udp), [`sockets.tcp`](https://developer.chrome.com/docs/apps/reference/sockets/tcp) and [`sockets.tcpServer`](https://developer.chrome.com/docs/apps/reference/sockets/tcpServer) APIs.
